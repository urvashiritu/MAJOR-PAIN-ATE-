MAJOR-PAIN-ATE // Laptop 2 Demo Kit

Browser-only kit — nothing to install on this laptop. Edge works out of the box.

One-time setup on LAPTOP 1 (the Linux machine)

1
Start the demo server there:
make demo-reset   # fresh slate (stop any running backend first) make demo         # starts the server on port 5000
2
Find its IP address:
hostname -I | awk '{print $1}' Write it down — something like 192.168.1.42.
3
If laptop 2 cannot connect later, allow the port through the firewall:
sudo ufw allow 5000/tcp  (only needed if a firewall is active)

On THIS laptop (Laptop 2 / Windows 11)

A
Make sure you are on the same Wi-Fi / LAN as laptop 1 (turn VPN off).
B
Double-click: open-login-page.bat Type laptop 1's IP when asked and press Enter.
The login website opens — persona cards, custom login form, ATTACK button.
C
(Optional) double-click open-dashboard.bat to also watch the SOC dashboard live from here.
If Windows shows a blue SmartScreen warning for the .bat files: click More info → Run anyway. They are our own two-line launchers.
