MAJOR-PAIN-ATE // Laptop 2 Troubleshooting
==========================================

Problem: "This site can't be reached" / page won't load
  1. Are both laptops on the SAME Wi-Fi / LAN? (VPN off on laptop 2)
  2. Is laptop 1's server running?  (on laptop 1:  make demo)
  3. Did you type the IP with no extra spaces?  (on laptop 1:  hostname -I)
  4. Firewall on laptop 1 blocking port 5000?
        sudo ufw allow 5000/tcp        (or: sudo ufw status  to check)
  5. Try from laptop 1 itself first:  http://127.0.0.1:5000/
     - works there but not from here  -> firewall/IP issue (steps 1-4)
     - doesn't work there either      -> restart: make demo-reset && make demo

Problem: Windows SmartScreen / "Windows protected your PC"
  Click: More info -> Run anyway.
  The .bat files are two-line launchers made for this demo.

Problem: .bat window flashes and closes instantly
  Right-click the .bat -> Open with -> Command Prompt, read the error,
  or open a Command Prompt manually, cd into this folder, type the name.

Problem: Page loads but dashboard shows nothing new when I log in
  - Refresh the dashboard tab (it reconnects its live stream).
  - Confirm the browser URL uses the SAME IP you tested.

Demo-day quick recipe
  Laptop 1:  make demo-reset   then   make demo
  Get IP:    hostname -I | awk '{print $1}'
  Laptop 2:  double-click open-login-page.bat, type that IP, present.
