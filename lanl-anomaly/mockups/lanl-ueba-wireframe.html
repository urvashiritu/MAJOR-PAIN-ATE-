Proposed · ingest
Log tailer → queue → existing score_event(). One path for real events; the replay stays as a labelled demo mode instead of pretending to be live.
Proposed · persistence
SQLite tables: events, alerts, cases, labels. Replaces the in-memory ack set; survives restart.
Proposed · feedback loop
Confirmed / false-positive writes a label. Baselines updates per event. Retrain consumes labels, so the product closes.

Verified starting point

Highest-leverage change

Sequencing
Ingest → persistence → triage → labels → incremental baselines. Each step is independently demoable.
