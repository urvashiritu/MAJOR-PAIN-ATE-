Reading the replay
honest limits
01
Session ≠ model quality.

20/20 in this window looks perfect. Held-out recall is 56.7% (136/240) — that is the number that survives outside this 33-minute sample.

02
Every alert came from one source.

All 21 alerts in this window originate from C17693. That is a property of this replay, not a rule you can generalize.

03
False positives have a human cost.

12 normal logins were blocked. Each one is a person who could not work, and each one spends analyst attention that a real attack needs.

What this replay does not prove

A 33-minute window with 20 attacks is a demo, not a benchmark. Quote the held-out strip — not the session catch rate — when you talk about model quality.
